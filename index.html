THE PROCESS

One conversation. Three parts.

Voice on the front. A text model behind the scenes. GitHub at the finish line.

01 / SPEAK

Start with a voice

An idea is described naturally in ChatGPT Voice. No technical brief or code editor required.

02 / BUILD

ChatGPT creates

The voice experience hands the task to the text model, which plans and writes the actual project files.

03 / SHIP

GitHub publishes

Using the GitHub connection, ChatGPT adds the files to this repository so the result can be shared.
